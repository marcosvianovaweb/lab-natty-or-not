PeopleHub - Aplicativo Corporativo de RH 🚀
📒 Descrição

O PeopleHub é um conceito visual de aplicativo mobile corporativo (Employee Self-Service) projetado para centralizar e simplificar a rotina dos colaboradores de uma empresa. O aplicativo permite consultar saldos, solicitar férias, gerenciar benefícios e acessar informações essenciais em uma interface moderna e intuitiva.

🤖 Tecnologias Utilizadas
Microsoft Copilot (Texto): Utilizado para atuar como Product Manager corporativo, estruturando a proposta de valor, regras de negócio e o detalhamento visual das telas principais.
Microsoft Copilot / Designer (Imagem): Utilizado para gerar uma fotografia hiper-realista em ambiente corporativo simulando o uso do aplicativo em um smartphone.
🧐 Processo de Criação
Definição da dor de mercado: Foco na digitalização de processos de Recursos Humanos para reduzir chamados e dar autonomia aos funcionários.
Engenharia de Prompt (Texto): Criação de um prompt estruturado para definir o nome PeopleHub, princípios de UX e a organização de 3 telas: Dashboard, Solicitação de Férias e Carteira de Benefícios.
Engenharia de Prompt (Imagem): Prompt detalhado para criar uma foto com iluminação natural de um escritório moderno com a interface limpa e legível na tela do celular.
